# Tayper

Um jogo de digitação escrito utilizando a linguagem Java 25 em conjunto com a biblioteca Raylib.

## Compilando

Para compilar o jogo, basta apenas ter o [OpenJDK](https://openjdk.org/) 25+ e o [Make](https://www.gnu.org/software/make/) instalados em sua máquina. O repositório conta com um Makefile capaz de instalar a [Jaylib](https://github.com/electronstudio/jaylib/), compilar e executar o jogo automaticamente em sistemas POSIX apenas chamando o programa sem argumentos.

```bash
make
```
