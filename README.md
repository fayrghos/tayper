# Tayper

Um jogo de digitação escrito utilizando a linguagem Java 25 em conjunto com a biblioteca Raylib.

## Compilando

Para compilar o jogo, basta apenas ter o [OpenJDK](https://openjdk.org/) 25+ instalado em sua máquina. O projeto utiliza um [Gradle Wrapper](https://docs.gradle.org/current/userguide/gradle_wrapper.html) embutido para para auxiliar no build, bastando apenas chamar seu script.

```sh
./gradlew run
```
